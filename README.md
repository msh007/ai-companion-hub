# AI Companion Hub

A modern directory website for AI girlfriend and companion apps, inspired by popular review sites.

## Features

- Age verification gate (18+)
- Responsive dark theme design
- Tool cards with ratings, tags, and CTAs
- Categories, leaderboard, guides, and news sections
- Search bar and quiz placeholder
- Ready for GitHub Pages

## How to use

1. Clone or download the repository
2. Open `index.html` in a browser
3. Or deploy to GitHub Pages

## Tech

- Pure HTML, CSS, JavaScript
- No dependencies
- Inter font from Google Fonts
